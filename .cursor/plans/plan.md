Я хочу в этом репозитории сделать тестовое web pwa приложение которое будет выполнять следующий сценарий:

Пользоватьель заходит на url
В браузере видит предложение установить эту страницу как PWA
Устанавливает
В приложении три экрана:
    1. ввод имени, при подтверждении имени должна быть проверка на уникальность этого имени
    2. После ввода имени, пользователь попадает на экран с уже зарегистрированными именам и выбирает одно из них, себя он тоже видит.
    3. После выбора конкретного имени на экране появляется окно для ввода текста где видно кому мы отправляем сообщение. Отправка происходит по нажатию на кнопку самолетика


В сообщинии на сервере виден текст сообщения от кого и кому оно предназначается
При регистрации имени должен приходить так же id полученные от сервиса доставки Push уведомлений и id устройства
В таблице с пользователями мы храним имя, id устройства и id в сервисе push уведомлений
Таблица с сообщениями хранит сами сообщения, кто отправил, кому отправил, статус доставки push уведомления

После получения команды отправки сообщения мы его передаем сервису PushHive, который должен крутиться в контейнере рядом
